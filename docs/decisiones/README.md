# Registro de decisiones (ADR)

Una decisión importante por archivo, numerada y fechada. Formato ligero:
**contexto → decisión → consecuencias**.

## Reglas

1. **No se editan retroactivamente.** Si una decisión se revierte, se escribe
   una nueva que la sustituye y se marca la vieja como «Sustituida por
   ADR-XXXX». El valor está en poder ver *por qué* se pensó algo entonces.
2. Se registra lo que **cambia el rumbo**, no cada detalle técnico.
3. Se escribe **cuando se toma** la decisión, no después.
